# Development Process

## Project Background

AthletePal was developed as part of a Software Engineering module at the University of Leeds.

The objective was to design and build a complete full-stack fitness application whilst working within a collaborative development team using modern software engineering practices.

---

# Development Approach

The project followed an Agile software development methodology.

Development was organised into iterative sprints, allowing features to be planned, implemented, tested and refined throughout the project lifecycle.

Regular meetings and collaborative planning ensured that work remained coordinated across both frontend and backend development.

---

# Software Engineering Practices

Throughout development the team adopted a number of industry-standard practices including:

- Git version control
- Feature branching
- Pull requests
- Code reviews
- Incremental feature development
- Collaborative debugging
- Sprint retrospectives

These practices helped maintain code quality whilst allowing multiple developers to work on the application simultaneously.

---

# Technical Challenges

As with most collaborative software engineering projects, one of the biggest challenges was ensuring that independently developed features integrated smoothly into a single application.

This required careful communication, consistent coding practices and regular testing throughout development.

Another important challenge was maintaining a consistent user interface whilst multiple developers were contributing to different parts of the frontend.

---

# Reflection

AthletePal provided valuable experience beyond simply writing code.

Working within a larger development team helped me understand the importance of communication, planning, version control and maintainable software architecture.

The project reinforced that successful software engineering is not only about building features, but also about collaborating effectively and producing software that is reliable, maintainable and user-focused.
